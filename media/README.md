# media/

Coloque aqui os arquivos usados pelo bot:

- `welFolder/` — imagens sorteadas aleatoriamente para mensagens de boas-vindas (`.jpg`, `.png`, `.gif` ou `.webp`).
- `goodFolder/` — imagens sorteadas aleatoriamente para mensagens de despedida.
- `banFolder/` — reservada para uso futuro por um plugin de moderação (ex.: imagem ao banir alguém).

Se uma pasta estiver vazia, o bot simplesmente envia a mensagem em texto puro, sem imagem.

> Este repositório não inclui um `black.jpg` padrão — adicione a sua própria imagem em `banFolder/` se quiser usá-la.
